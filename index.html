Formula help

ChartForge uses lightweight Excel-style A1 references. Type formulas beginning with = in a cell.

  • Arithmetic: =B2+C2, =B2*C2, =(B2+C2)/2, =B2^2
  • Aggregates: =SUM(B2:B10), =AVERAGE(B2:B10), =MIN(B2:B10), =MAX(B2:B10)
  • Counts: =COUNT(B2:B10), =COUNTA(B2:B10)
  • Functions: =ABS(C2), =SQRT(C2), =ROUND(C2,2)
  • Keyboard: Enter commits, Esc restores, arrow keys move selection.

Formulas are calculated locally. This is intentionally a compact formula engine, not a complete Microsoft Excel implementation.
