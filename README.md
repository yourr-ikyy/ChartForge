## English

**ChartForge** is a lightweight browser-based data visualization tool that combines a spreadsheet editor, formula system, chart builder, data analysis, and dashboard features into a single HTML application.

No installation required. Open the HTML file and start working with your data.

### Features

- Spreadsheet-style data editor
- Formula engine with common functions
- Formula autocomplete
- Multiple sheets
- Cross-sheet formulas
- Calculated columns
- Data filtering and sorting
- Data cleaning tools
- Column type detection
- Smart chart recommendations
- Automatic chart generation
- Interactive charts
- Advanced chart customization
- Custom chart themes
- Auto insights
- Anomaly detection
- KPI cards
- Dashboard mode
- Drag & resize dashboard widgets
- What-if analysis
- JSON / CSV / XLSX import
- JSON / CSV / XLSX export
- SVG and high-resolution PNG export
- `.chartforge` project save/load
- API / URL data import
- Command Palette
- Keyboard shortcuts
- Dark mode
- Responsive layout

### Chart Types

Bar · Line · Area · Scatter · Pie · Doughnut · Radar · Funnel · Gauge

### Quick Start

1. Download the HTML file.
2. Open it in a modern browser.
3. Import your data or enter it manually.
4. Build formulas and calculations.
5. Create or customize your chart.
6. Export the result.

<details>
<summary>What makes ChartForge different?</summary>

ChartForge is designed around a simple workflow:

`DATA → CALCULATE → ANALYZE → VISUALIZE → EXPORT`

It combines spreadsheet-like editing with interactive visualization and lightweight data analysis without requiring a separate desktop application.

</details>
